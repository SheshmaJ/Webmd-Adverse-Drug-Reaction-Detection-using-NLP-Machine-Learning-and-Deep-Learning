# Dataset

## WebMD Drug Reviews Dataset

This project uses the **WebMD Drug Reviews Dataset**, which contains patient-reported drug reviews and related information.

- **Original Review Source:** [WebMD](https://www.webmd.com/)
- **Dataset Source:** [WebMD Drug Reviews Dataset – Kaggle](https://www.kaggle.com/datasets/rohanharode07/webmd-drug-reviews-dataset)

The original dataset contains **320,094 records and 12 variables**. The target variable used for ADR classification is constructed during the data preprocessing stage.

## Download Instructions

The original dataset is not included in this GitHub repository due to its large file size.

Download the dataset from:

[Download the WebMD Drug Reviews Dataset from Kaggle](https://www.kaggle.com/datasets/rohanharode07/webmd-drug-reviews-dataset)
